Machine Learning-Guided Screening of MOFs for Photocatalytic CO₂ Reduction

This repository contains the source code for literature data extraction, electronic property prediction, and machine learning-based high-throughput screening of metal–organic frameworks (MOFs) for photocatalytic CO₂ reduction.

Code Structure

C1-C2-C3: Machine learning models for photocatalytic activity, performance, and product selectivity prediction.
EA and IP: Electron affinity (EA) and ionization potential (IP) prediction.
Eg: Band gap prediction using transfer learning.
llm_extraction: Literature data extraction using large language models (LLMs).

Screening Workflow

PLD Filtering → Band Gap Filtering → EA/IP Filtering → C1 Activity Prediction → C2 Performance Prediction → C3 Product Selectivity Prediction

Data Availability

The repository provides the experimental datasets, model-related code, and screening results associated with this study.
